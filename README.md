## Getting Started

### Clone the Repository

```bash
git clone https://github.com/samanemami/DLFBT-LAB.git
cd DLFBT-LAB
```

### Install the Required Libraries

```bash
pip install -r requirements.txt
```

If an additional library is required and is not included in `requirements.txt`, install it manually:

```bash
pip install library_name
```

For example:

```bash
pip install tensorflow
```

## Laboratory Exercises

- The assignments must be completed **in pairs**.
- All exercises and explanations are provided in the corresponding Jupyter notebooks (`.ipynb`).
- Your solutions must be implemented **only in the corresponding Python (`.py`) file**.
- Complete only the sections marked with:

```python
# TO-DO
```

> **Important:** Do **not modify the Jupyter Notebook (`.ipynb`) files**.  
> The notebooks are provided only to describe the exercises, run the experiments, and check your results.
>
> You **do not need to submit the notebooks**. Submit only the Python file requested for each laboratory.

The repository contains two laboratory assignments and one final project:

- [Lab 1](#lab-1)
- [Lab 2](#lab-2)
- [Final Project](#Final-project)

### Submission Rules

- Do **not** submit the `.ipynb` notebook files.
- Do **not** modify the notebook files.
- Do **not** add code outside the sections marked with `TO-DO`.
- Make sure your code runs correctly before submission.
- Include the **full names and NIAs of both students** at the beginning of the Python file.

Upload the requested file to the [course Moodle page](https://posgrado.uam.es/course/view.php?id=72922) before the corresponding deadline.
